# Dowry-System-Analysis
This project analyzes dowry-related data to identify trends, patterns, and social impact using data analytics tools. The dashboard/report helps in understanding factors affecting dowry practices through visualizations and insights.  
**Tools Used**
Python
SQL
Power BI
Excel
Features
Data cleaning and preprocessing
Interactive dashboard
Trend analysis
Data visualization
Insights generation

**Objective**

The main objective of this project is to spread awareness and provide data-driven insights about the dowry system and its impact on society.

**Dataset**

The dataset includes information related to dowry cases, demographics, and regional statistics.

**Conclusion**
This project highlights important patterns and supports better understanding of social issues through data analytics.
